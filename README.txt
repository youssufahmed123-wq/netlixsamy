How to run:
1. Extract the project folder.
2. Keep the image folder beside index.html and style.css.
3. Open index.html in your browser (internet is needed for Bootstrap and the remote feature images).
4. Register a demo account, then sign in.

Important:
- The hero background uses the local file image/elLovers.png.
- Login/register use browser localStorage for a coursework demo only.
- Do not use this front-end-only password storage for a real website.
